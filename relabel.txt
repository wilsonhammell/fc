# Labels restyle_pdf.py --relabel swaps for the house wording.
#
#   printed label => replacement
#
# A label only matches when it is the WHOLE line. Case, curly apostrophes,
# spacing and a trailing colon don't matter, and a colon is kept if the form
# had one. ALL-CAPS labels come out in capitals. A word inside a sentence is
# never touched, and a label is left alone - and listed for a human - if it's
# part of a paragraph or the new wording wouldn't fit where it sits.
#
# A comment is a whole line starting with "#". A "#" inside a line is part
# of the label ("Owner #").
#
# Chosen 2026-09-19 from the labels that appear in the 11 sample forms.
# Anything not listed is for a human; the report lists lines that mention a
# witness or staff so they can be found.

# iv. Witness / staff references -> Authorizing Staff Member
# A bare "Witness" is the first column of a member's signing row, and the
# client's signing area is Authorized Name | Authorized Signature | Date
# (review notes 2026-09-22; their own hand-cleaned forms do the same).
# A witness the form names as Libro's or the credit union's stays staff.
Witness                                 => Authorized Name
Signature of Witness                    => Authorizing Staff Member
Witness' Signature                      => Authorizing Staff Member

# v. Member signing -> Authorized Signature
# (the member signs as "Producer", "Borrower" or "Mortgagor" depending on
#  the form; as whole labels only - the agreements say "the Borrower" hundreds
#  of times in their text, and that is never touched)
Signature(s) of Producer(s)             => Authorized Signature
Signature of Producer                   => Authorized Signature
Signature of Producer / Breeder Grower  => Authorized Signature
Director's (Producer) Signature         => Authorized Signature
Borrower                                => Authorized Signature
Mortgagor                               => Authorized Signature

# v. Member name -> Name (the number is kept where a form has two signers)
Owner(s) Name                           => Name
Director's (Producer) Name              => Name
Owner/Signing Officer Name 1            => Name 1
Owner/Signing Officer Name 2            => Name 2

#   Licence / Account Name                 these name something other than the member
